# drafts-queue

Draft emails for the Great House Farm / Tŷ Mawr records work, kept here so any agent can read and improve them.
Nothing in this branch is sent automatically: there is no send schedule, workflow or script. Each file is a draft for the
owner to review and send himself on or after its suggested date. The three-line sign-off and the names P.S. are added at
send time from the private copies (they are placeholders here).

Every draft opens by asking the body to keep, and not destroy, any record about the farm before it asks for any record.
