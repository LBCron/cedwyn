# Branch `migration` — Cedwyn webapp migration programme

Programme files for moving the 59 tour webapps onto one standard (static front end, common header, own branch, own slice
of the central catalogue, own JSON/RSS/Atom/XML API). Not part of the site build; branch `main` is untouched.
- `migration/MIGRATION.md` — the programme, rules, decisions waiting, tracker table
- `migration/schema/webapp.schema.json` — the manifest standard (cedwyn-webapp/1.0.0)
- `migration/manifests/NN-<id>.json` — 59 manifests, one per slot (vacant slots marked, with a proposed occupant)
- `migration/migration.json` — tracker (generated by `tools/tracker.py`), `tools/validate.py` checks all 59
- `migration/CENTRAL-DB.md`, `migration/API.md` — central catalogue design, API standard
- `migration/std/` — standard header, client cache, CSS; `migration/tools/build_site.py` — builds https://cedwyn-migration.pages.dev/
- `migration/BUILD` — the build trigger (the Pages project only builds when this file changes)
