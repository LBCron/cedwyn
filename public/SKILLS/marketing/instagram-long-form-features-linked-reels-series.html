Instagram long-form (Oct 2026): 90-minute "Features", linking Reels, Series

Harvested 2026-11-04. Status: PREP NOW, GATE on Features. Source is an agency news write-up (ALM Corp, 4 Nov 2026, read). Instagram's own post was seen only as a search snippet (instagram.com, "(re) launching their long-form video feature"). Treat the details as not checked against an Instagram help page.

What changed

  • Features: long-form video uploads up to 90 minutes, aimed at "podcasts, vlogs and interviews". A test that started 26 Oct 2026 with select US creators. Shown by Adam Mosseri (Head of Instagram) and Tessa Lyons (VP Product) as the main item in a set of long-form updates. Instagram is going back to long video years after IGTV.
  • Linking Reels: creators can chain up to 8 Reels clips together, so a viewer moves from one clip to the next. The write-up calls this "Clips as Reels".
  • Series (in development): group several Reels under one theme.
  • Connected TV app: the phone will act as a remote. Long viewing on TV is where this is heading.
  • No reach or watch-time numbers published yet. Anyone quoting an uplift today is guessing.

How to use it (small account, no spend)

  1. Linking (available in the app): after posting a run of Reels on one subject, open each Reel's edit/link option and link the next one, up to 8. Order them as a story: the cliffhanger first, the payoff last.
  2. Series (when it reaches the account): one Series per lasting theme. Name it the way people search, e.g. "Farm records, 1840-1987", not "Part 1".
  3. Features (gate): check the upload sheet once a month. When long-form appears, upload the full film in one language with burned-in subtitles and chapters in the caption. Pin it. Point every short Reel's caption at it ("full film on our profile"), never at an outside link.
  4. Measure: for each linked chain, compare clip 1 views with clip 8 views. That drop-off is our per-scene completion number on Instagram (same idea as tools/scene_completion.py). Keep the chain order that holds people longest.

Guardrails

  • Originality rules still apply (see facebook-reels-originality-archive-clips.md and the originality skills): our own edits of our own scenes are original; re-uploads of other people's footage are not.
  • AI lip-synced scenes need the AI label (ai-lip-sync-dubbed-documentary-disclosure-youtube-meta.md).
  • Within the existing cap of 1 auto-post a day. Linking is a manual edit in the app, not a scripted action, unless the Graph API exposes it (not checked; it is not in the API docs we hold).

How we apply it to Cedwyn

  • The documentary is made scene by scene (one dated moment per scene, cy/en/es). That fits linked Reels exactly: post each finished scene's 60-90 s cut in date order, then link them so a viewer can watch Roman to modern in a row. Start with the scenes already live (doors 1-2 and on), one language per chain (English first, then a Welsh chain).
  • When Series reaches @cedwynestate, create "Cedwyn: the film, scene by scene". Every Reel caption ends with the one shop line already in use (/ebooks/), with no extra links.
  • When Features reaches non-US accounts, the whole film (or a 20-40 min cut) goes up natively. Log it as a PROPOSAL for the movie runner, not something done automatically.
  • Write one line to the project workspace when linking is first used, then track clip-1 vs clip-8 views weekly.
